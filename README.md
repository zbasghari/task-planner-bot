# 🤖 ایجنت تعاملی برنامه‌ریزی شخصی

بات تلگرامی هوشمند برای مدیریت کارها و زمان‌بندی شخصی

## ✨ قابلیت‌ها

- 📝 افزودن کار با اولویت و مهلت
- ⚡ زمان‌بندی خودکار هوشمند
- 📌 رویدادهای ثابت (باشگاه، تدریس و...)
- 📅 برنامه روزانه و هفتگی
- 📈 آمار عملکرد
- ⚙️ تنظیمات شخصی

## 🚀 نصب و اجرا

### ۱. پیش‌نیازها

- Python 3.8+
- توکن ربات تلگرام (از @BotFather)

### ۲. نصب

```bash
# کلون کردن پروژه
cd task-planner-bot

# نصب وابستگی‌ها
pip install -r requirements.txt
```

### ۳. تنظیم توکن

```bash
# لینوکس/مک
export TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE"

# ویندوز (PowerShell)
$env:TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE"
```

### ۴. اجرا

```bash
python bot.py
```

## 📋 دستورات

| دستور | توضیح |
|-------|-------|
| `/start` | شروع و ثبت‌نام |

| `/list` | لیست کارها |

| `/fixed` | رویداد ثابت |
| `/fixedlist` | لیست رویدادها |
| `/stats` | آمار عملکرد |

| `/sethours` | تنظیم ساعت کاری |
| `/help` | راهنما |

## 🎯 اولویت‌ها

- 🔴 **فوری (۴):** بیشترین اولویت
- 🟠 **مهم (۳):** اولویت بالا
- 🟡 **معمولی (۲):** اولویت متوسط
- 🟢 **کم‌اهمیت (۱):** اولویت پایین

## 🔧 سفارشی‌سازی

### تغییر ساعت کاری پیش‌فرض

در فایل `database.py`:

```python
# مقادیر پیش‌فرض
daily_hours = 8
work_start_hour = 9
work_end_hour = 17
```

### تغییر دسته‌بندی‌ها

در فایل `bot.py`:

```python
CATEGORY_EMOJI = {
    "work": "💼",
    "coding": "💻",
    # اضافه کردن دسته جدید
    "custom": "🎯",
}
```

## 📊 الگوریتم زمان‌بندی

زمان‌بند هوشمند بر اساس ۵ عامل کار می‌کند:

1. **اولویت (۳۵٪):** کارهای فوری‌تر زودتر
2. **مهلت زمانی (۳۵٪):** نزدیک‌تر به مهلت = زودتر
3. **سن کار (۱۵٪):** کارهای قدیمی‌تر اولویت دارند
4. **دسته‌بندی (۱۰٪):** کارهای کاری و کدنویسی صبح‌ها
5. **انرژی (۵٪):** تطبیق با سطح انرژی روز

## 🐛 عیب‌یابی

### خطا: ModuleNotFoundError

```bash
pip install -r requirements.txt
```

### خطا: Invalid token

مطمئن شوید توکن صحیح از BotFather دریافت کرده‌اید.

### خطا: Database locked

فقط یک نمونه از بات روی یک دیتابیس اجرا شود.
